# معرفی پروژه

این پروژه با هدف مانیتورینگ لحظه‌ای دستگاه‌های CNC و ذخیره‌سازی اطلاعات تولید طراحی شده است.

بردهای CNC در هنگام تولید، اطلاعات مختلفی را از طریق یک پروتکل اختصاصی مبتنی بر TCP/IP به سرور ارسال می‌کنند. این اطلاعات پس از Decode شدن، در پایگاه داده ذخیره شده و در قالب Sessionهای تولید پردازش می‌شوند تا امکان تحلیل، گزارش‌گیری و نمایش وضعیت دستگاه‌ها فراهم شود.

این پروژه علاوه بر پیاده‌سازی سرور ارتباطی، شامل مستندسازی و مهندسی معکوس پروتکل اختصاصی دستگاه‌ها نیز می‌باشد.

# پروتکل ارتباطی

ارتباط بین بردهای CNC و سرور از طریق TCP انجام می‌شود.

| ویژگی    | مقدار    |
| -------- | -------- |
| Protocol | TCP      |
| Port     | 100      |
| Header   | 45 00    |
| Payload  | Variable |
| CRC      | دو بایت  |

---

# ساختار Packet

هر Packet از بخش‌های زیر تشکیل شده است:

| بخش         | توضیح          |
| ----------- | -------------- |
| Header      | شروع Packet    |
| Address     | آدرس دستگاه    |
| DeviceCode  | شناسه دستگاه   |
| Setting     | تنظیمات        |
| PayloadSize | اندازه Payload |
| Payload     | اطلاعات اصلی   |
| CRC         | کنترل خطا      |

نمونه:

```text
45
00 A9
54 4E 43 32 33
02
04
00 BA 00 00
00 00
```

# پردازش Sessionهای تولید

هر Session از مجموعه‌ای از Packetها تشکیل می‌شود.

```text
Start
   │
Quantity
   │
Quantity
   │
Quantity
   │
Scrap / Forms
   │
Stop
```

پردازشگر Session به صورت دوره‌ای Packetهای پردازش نشده را خوانده و اطلاعات Session را تکمیل می‌کند.
